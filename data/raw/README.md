# Raw-data setup

Download the Olist CSV archive from the dataset link in the project README and extract these files directly into this folder:

- `olist_orders_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_products_dataset.csv`
- `product_category_name_translation.csv`

Do not rename the files. They are excluded from version control, so the project can be shared without redistributing third-party data.

`olist_geolocation_dataset.csv` and `olist_sellers_dataset.csv` are useful optional extensions for a later map or seller-analysis sprint, but the first dashboard does not need them.
